# 🌐 My Portfolio

This repository contains the source code for my **personal portfolio website**, showcasing my **experience, projects, skills, and certifications**.  
The portfolio is designed to serve as a central hub where recruiters, collaborators, and peers can learn more about me.  

🔗 **Live Demo:** [shivannasneha.com](https://shivannasneha.com)  

---

## 📌 Features
- 🖥️ **Responsive Design** – works across desktop, tablet, and mobile.  
- 📜 **About Me Section** – background, career goals, and education.  
- ⏳ **Timeline / Roadmap** – professional and academic milestones.  
- 💼 **Experience Section** – details of industry roles and projects.  
- 📊 **Projects Showcase** – links to GitHub repositories and demos.  
- 📑 **Certifications Section** – professional certifications & badges.  
- 📬 **Contact Section** – links to LinkedIn, GitHub, and email.  

---

## ⚙️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript  
- **Styling:** Custom CSS (with animations, pastel themes)  
- **Deployment:** GitHub Pages / Custom Domain
